## Overview
SmartBudget Manager is an Excel workbook that helps users record income and expenses, organize expenses by category, and monitor a monthly budget.
It has:
- **Dashboard:** displays total income, total expenses, monthly balance, budget status, category summary, and a chart.
- **Transactions:** stores each transaction's date, description, type, category, income, expense, and notes.
- **Categories:** lists the available expense categories and their monthly budget values.

## Requirements
- Microsoft Excel 2016, 2019, 2021, Microsoft 365, or compatible spreadsheet software.
- Basic skills such as entering data in cells and saving a workbook.

## Getting started
1. Open `the Excel workbook file.
2. Go to **Transactions** and enter each transaction on the next empty row.
3. Select **Income** or **Expense** in the Type column.
4. For expenses, choose a category and enter the amount in the Expense column. For income, enter the amount in the Income column.
5. Review or update budget values in **Categories**.
6. Open **Dashboard** to review totals, remaining budget, status, and the chart.
7. Save your changes with **Ctrl+S**.
